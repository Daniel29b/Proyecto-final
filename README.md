# Proyecto-final
Este es el proyecto final para la materia base de datos avanzada de Daniel Zepeda Cervantes

La siguiente es una base de datos simple que recopila datos sobre novelas visuales

Lista de comandos:

Tabla studios:
-call getallstudios(); Regresa la tabla de todas los estudios disponibles
-call getstudiobyid(); Regresa un estudio en especifico
-call createstudio(); Añade un estudio a la tabla
-call updatestudio(); Actualiza un registro
-call deletestudiobyid(); Elimina un registro
-call deleteallstudios(); Elimina todos los estudios


Tabla writers:
-call getallwriters(); Regresa la tabla de todas los escritores disponibles
-call getwriterid(); Regresa un escritor en especifico
-call createwriter(); Añade un escritor a la tabla
-call updatewriter(); Actualiza un registro
-call deletewriteryid(); Elimina un registro
-call deleteallwriters(); Elimina todos los escritores

Tabla genres:
-call getallgenres(); Regresa la tabla de todas los generos disponibles
-call getgenreid(); Regresa un genero en especifico
-call creategenre(); Añade un registro a la tabla
-call updategenre(); Actualiza un registro
-call deletegenrebyid(); Elimina un registro
-call deleteallgenres(); Elimina todos los generos
